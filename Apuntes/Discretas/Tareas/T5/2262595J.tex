\section*{Pregunta 1}

\subsection*{(a)}
Sean $f, g: \mathbb{N} \rightarrow \mathbb{R^+}$ funciones arbitrarias. Se define la función máximo como:

$max\{ f(n), g(n)\} = 
\begin{cases} 
f(n) & \text{si } f(n) \geq g(n) \\ 
g(n) & \text{si } f(n) \leq g(n)
\end{cases}
$

Luego, por definición de notación $O$, se tiene que:

$f(n) \in O(g(n)) \leftrightarrow \wedge \exists c > 0 \exists n_0 \in \mathbb{N} :f(n) \leq c \cdot g(n) \forall n \geq n_0$.

Nótese que la suma de funciones será siempre menor o igual que el doble del máximo de las mismas, con lo que se cumple para $c = 2, n_0 = 0$:

$f(n) + g(n) \leq 2 \cdot max\{f(n), g(n)\}$.

Finalmente, se tiene que $f(n) + g(n) \in O(max\{f(n), g(n)\})$.

\subsection*{(b)}

Sea el algoritmo definido en el enunciado.

El peor caso será cuando $A_1$ y $A_2$ retrornados por \textit{Particionar} sean lo más desbalanceado posible.

Para que lo anterior sea cierto, debe cumplirse que $q = max\{A[0], A[1], ..., A[n-1]\}$.

Lo anterior implica que los arreglos retornados por \textit{Particionar} serán $A_1 = A$ y $A_2 = \emptyset$.

Si lo anterior ocurre, se dará que $B_1 = QuickSort(A, largo(A))$, lo que cual será el mismo que el llamado inicial.

Esto implica que en el peor caso se daría una recursión infinita, llamándose a $QuickSort(A, largo(A))$ siempre, 
con lo que se da un tiempo indefinido.
