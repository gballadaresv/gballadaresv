### Logging

##### Undo

Se escribe el valor antiguo en el log.

Se lee de arriba a abajo (antes primero).

Se deshacen los cambios de todas las transacciones que no tengan commit.

Si hay commit o abort, se ignora la transacción (ya se commiteó o ya se deshizo).

Si hay un checkpoint con end, se hace undo de todo lo que venga después del start.

Si hay un checkpoint sin end, se mira desde el inicio de la transacción abierta con el start más antigua.



##### Redo

Se escribe el valor nuevo en el log.

Se lee desde abajo hacia arriba (después primero).

Si se lee end está ok.

Buscamos las transacciones que tienen commit sin end.

Si no se hizo commit no se hace nada (abort).

Si hizo commit, actualizar con el nuevo valor (pq no hizo end).

Si hay un start sin su end, hay que retrocedes hasta el end más antiguo.
