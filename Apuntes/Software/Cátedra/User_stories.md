### Administador
1. Como administrador, quiero poder iniciar sesión para tener acceso todas las funcionalidades y herramientas asociadas a mi tipo de usuario.

- Condiciones de satisfacción: Dado que soy un administrador registrado, cuando presione el botón de iniciar sesión, entonces quiero poder usar mi usuario y contraseña para acceder a la página.
- Storypoints:  1


2. Como administrador, quiero poder eliminar usuarios de la plataforma, para mantener un mejor ambiente de aprendizaje.

- Condiciones de satisfacción: Dado que soy un administrador registrado, cuando presione el botón de eliminar usuario, entonces quiero que el usuario en cuestión sea eliminado de la plataforma, avisando al usuario que su cuenta fue eliminada cuando intente iniciar sesión.
- Storypoints:  3



3. Como administrador, quiero poder eliminar publicaciones que puedan considerarse inapropiadas, para mantener un mejor ambiente de aprendizaje.

- Condiciones de satisfacción: Dado que soy un administrador registrado, cuando presione el botón de eliminar publicación, entonces quiero que la publicación se elimine del curso.
- Storypoints: 3



4. Como administrador, quiero poder eliminar cursos para poder gestionar de mejor forma los cursos activos.

- Condiciones de satisfacción: Dado que soy un administrador registrado, cuando presione el botón de eliminar curso, entonces quiero que el curso sea eliminado junto con todo su contenido.
- Storypoints: 3



6. Como administrador, quiero añadir y eliminar usuarios de un curso, para poder gestionar de mejor forma a los usuarios activos pertenecientes a distintos cursos.

- Condiciones de satisfacción: Dado que soy un administrador registrado, cuando presione el botón de añadir/eliminar usuarios en un curso, entonces los usuarios seleccionados serán añadidos o eliminados según corresponda. 
- Storypoints: 3



7. Como administrador, quiero asignar tipo de usuarios, para poder gestionar a las distintas personas de la página y sus respectivos privilegios.

- Condiciones de satisfacción: Dado que soy un administrador registado, cuando ingrese al perfil de un usuario, entonces quiero poder asignar cargos al usuario.
- Storypoints: 5


8. Como administrador, quiero restablecer contraseñas, para poder asistir a aquellos usuarios que olviden la suya.
- Condiciones de satisfacción: Dado que soy un administrador registado, cuando tenga una solicitud de cambio de contraseña, entonces quiero poder asignar una contraseña provisoria.
- Storypoints: 5


9. Como administrador, quiero poder buscar cursos y usuarios por sus nombres, para encontrar más fácilmente un curso o usuario en particular.

- Condiciones de satisfacción: Dado que soy un administrador registrado, cuando ingrese un curso o usuario en la barra de búsqueda, entonces me aparecerán los cursos o usuarios que coincidan con el nombre ingresado.
- Storypoints: 2




### Usuario no registrado
1. Como usuario no registado, quiero ver la lista de cursos disponibles, para poder decidir si un curso me parece interesante.

- Condiciones de satisfacción: Dado que soy un usuario no registrado, entonces veré un listado de los cursos disponibles.
- Storypoints: 2


2. Como usuario no registrado, quiero registrarme, para tener acceso a los contenidos del curso.

- Condiciones de satisfacción: Dado que soy un usuario no registrado, cuando presione el botón de registrarme, entonces podré registrar un nuevo usuario y contraseña a la página.
- Storypoints: 1
