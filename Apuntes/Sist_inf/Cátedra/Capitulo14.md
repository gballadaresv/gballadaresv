# IA en las organizaciones

Las IAs en el fondo son sistemas, que trabajan con información.
Reciben un input, hacen una transformación (según se entrene), da un output y se retroalimente sobre el resultado.

### Tipos de algoritmos de aprendizaje

Machine learning: árbol de desición

Deep learning: red neuronal

#### Machine learning

Aprendizaje a partir de datos en vez de instrucciones programadas.

Se podrían entrenar máquinas para detectar ataques y levantar alertas de ciberseguridad.

Cuando tengo muchos datos, lo primero es limpiarlos, luego se deja un 80% de los datos para entrenar el modelo, y un 20% para testeo.

Todo modelo se tiene que ir mejorando continuamente, la información no es estática, es mucha, variada y dinámica. Por eso es importante evaluar el desempeño del modelo.

#### Supervised Learning

Se entrenan modelos con datos etiquetados (con respuestas conocidas) para mediante inferencia estadística y algoritmos de regresión poder encontrar patrones con datos reales y hacer predicciones.

#### Unsupervised Learning

Aprendizaje sobredatos no etiquetados y se descubren patrones ocultos sin intervención. Se basa en métodos de agrupamiento y asociación para explorar y clasificar datos de manera autónoma.    

#### Reinforced Learning

Un tipo de aprendizaje automático donde un agende aprende a comportarse en un entorno cuyos resultados se recompensan o penalizan dependiendo si es correcto.

#### Deep learning

Es una técnica que se puede aplicar sobre los tipos de aprendizaje, se basa en múltiples capas de redes neuronales interconectadas.

El perceptrón es el bloque básico de una red neuronaal (similar a una neurona). Toma un vector de entrada, aplica una combinación lineal que entra al siguiente perceptrón, cada perceptrón ajusta los pesos de las entradas, para luego sumarse, y si se logra superar cierto valor (step function), se determina la desición o resultado final.

Mientras mayor la cantidad de capas y neuronas en cada capa, mayor serán la capacidad de computación requerida, afectando el rendimiento de la red.

Los parámetros de una red son los pesos y sesgos (bias) asociados a cada neurona. La cantidad de parámetros puede afectar la capacidad de la red para modelar datos complejos.

### Taxonomía de las IAs

- Weak IA: para realizar tareas específicas, no comprende ni experimenta consciencia.

- Strong IA: puede entender, aprender, adaptarse e implementar la inteligencia en una amplia gama de tareas. Teóricamente tiene consciencia, sentimientos y deseos propios. Aún no existe en la práctica.

*El BigData también se puede clasificar de distintas maneras.

### AI for buisness

Un conjunto de aplicaciones y soluciones basadas en IA para resolver problemas específicos del entorno empresarial.
Promueven una mayor eficacia y productividad, e impulsan la competitividad de las organizaciones.

Aportan en toma de decisiones, toma de procesos, experiencia del cliente e innovación de productos y/o servicios.
